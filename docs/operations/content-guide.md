## 1. Overview of Zero-Code CMS Management

MegaScript Digital is architected to allow the business team to publish, update, and manage all marketing content without touching application source code or requiring developer deployments.

### Content Categories Managed in /master/content:
- **Services Preview & Details**: 7 core and complementary service routes.
- **Product Marketing Pages**: 4 proprietary platforms (Fortress, LeaseFlow, UzaDigital, FM Scheduler).
- **Portfolio Case Studies**: 11 client showcase projects with outcome metrics.
- **Insights & Blog**: Educational articles, technical guides, and business analyses.
- **Client Testimonials**: Verified client quotes and partner accreditations.
- **Wow Factors**: Creative showpieces and interactive architectural highlights.

## 2. Managing Blog Articles & Technical Insights

### 2.1 Creating a New Article
1. Navigate to `/master/content` and select **Blog / Insights**.
2. Click **Create New Article**.
3. Fill in the structured fields:
   - **Title**: Clear, professional headline.
   - **Slug**: URL-friendly identifier (e.g. `integrating-mpesa-with-custom-web-applications`).
   - **Excerpt**: Concise summary (1–2 sentences) displayed on cards and search engine results.
   - **Cover Image**: Upload or supply high-resolution image asset.
   - **Body**: Structured markdown text. Use headings, bullet lists, and code blocks where helpful.
   - **Reading Time**: Calculated automatically or specified manually (e.g., `5 min read`).
   - **SEO Metadata**: Dedicated meta title and description for search engines.
4. **Draft vs. Published**:
   - Save as `DRAFT` while writing. Drafts are strictly excluded from public sitemaps and search indexing.
   - Select `PUBLISHED` when ready. Incremental Static Regeneration (ISR) updates the public route automatically.

## 3. Updating Portfolio Client Case Studies

1. Navigate to `/master/content/portfolio`.
2. Select an existing case study (e.g. *Lucky House Safaris*, *Luminary Mtaji Partners*, *Skrach Art*) or create a new entry.
3. Configure the commercial narrative:
   - **Client Name & Sector**: e.g., Eco-Tourism, Private Equity, Creative Studio.
   - **Challenge**: The business friction or technical limitation the client faced.
   - **Architecture & Solution**: The custom web or mobile system delivered by MegaScript Digital.
   - **Measurable Impact**: Key metrics (e.g., `+180% Inbound Inquiries`, `Sub-second Booking Speed`).
   - **Technology Tags**: Badges such as `Next.js`, `TypeScript`, `Tailwind CSS`, `PostgreSQL`.

## 5. Strict Editorial Discipline Guidelines

- **Zero Emojis Invariant**: Emojis are strictly forbidden across all website content, headings, body text, meta tags, and email notifications. Use clean, high-end technical typography and Lucide icons exclusively.
- **Zero Purple Gradients**: Visual backgrounds must adhere strictly to the corporate brand palette: Corporate Navy (`#0f172a`), Electric Cyan / Ocean Blue (`#0284c7`), and Vibrant Orange (`#ea580c`).
