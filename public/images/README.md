# MegaScript Digital: Static Image Assets Directory\n\nThis folder (public/images/) hosts approved static imagery and visual collateral for the website.\n\n## Directory Structure\n- logo/: Official vector SVG logos, marks, and wordmarks.\n- hero/: Hero background schematics and blueprint graphics.\n- services/: Graphics and vector illustrations for core and complementary service pages.\n- products/: High-resolution UI mockups and platform showcases.\n- portfolio/: Verified client case study project preview graphics.\n- team/: Approved team member and technical leadership portrait photos.\n- og/: Default social sharing cards (Open Graph / Twitter Card).\n\n## Brand Asset Guidelines\n- Palette: Strictly #0f172a (Corporate Navy), #0284c7 (Electric Cyan), and #ea580c (Vibrant Orange).\n- Prohibited: Zero purple gradients, zero emojis.\n- Formats: Prefer SVG for vector diagrams and WebP/AVIF for photographic assets.\n
